# Laporan Optimasi Proyek — 2026-10-10

Optimasi statis menyeluruh pasca-arsip (fokus: dependensi, dead code, kebersihan repo, keamanan .gitignore).
Dilakukan tanpa runtime (tidak ada bun/node/python di mesin eksekusi) — semua perubahan diverifikasi
dengan analisis import statis seluruh repo (57 file TS/TSX). Kontrak API, skema DB, dan logika bot
TIDAK diubah.

## 1. Dependensi package.json: 67 → 22 (−45 paket)

Semua dependensi yang tidak pernah di-import di seluruh repo (src, mini-services, scripts, tests)
dihapus. Yang tersisa persis 22 paket yang benar-benar dipakai:

@prisma/client, @radix-ui/react-{dialog,progress,select,separator,slot,switch,tooltip},
@tanstack/react-query, class-variance-authority, clsx, framer-motion, lucide-react, next,
next-themes, prisma, react, react-dom, socket.io-client, sonner, tailwind-merge, vaul.

Dampak: `bun install` jauh lebih ringan/cepat (paket berat seperti @mdxeditor/editor,
recharts, react-syntax-highlighter, react-day-picker, date-fns, @dnd-kit/*, next-auth,
next-intl, zod, zustand, uuid, sharp, z-ai-web-dev-sdk, dsb. tidak lagi diunduh),
build Next lebih cepat, permukaan dependency/audit lebih kecil.

Catatan: `bun.lock` lama masih memuat paket-paket tersebut — jalankan `bun install` sekali
di lingkungan platform untuk menyinkronkan lockfile.

## 2. Dead code dihapus (37 file + 1 folder)

- 36 komponen shadcn/ui yang tidak pernah di-import aplikasi (accordion, alert-dialog, alert,
  aspect-ratio, avatar, badge, breadcrumb, calendar, card, carousel, chart, checkbox, collapsible,
  command, context-menu, dropdown-menu, form, hover-card, input-otp, label, menubar,
  navigation-menu, pagination, popover, radio-group, resizable, scroll-area, sidebar, slider,
  table, tabs, textarea, toaster, toast, toggle, toggle-group). Tersisa 12 yang dipakai:
  button, dialog, drawer, input, progress, select, separator, sheet, skeleton, sonner, switch, tooltip.
- `src/hooks/use-mobile.ts` + `src/hooks/use-toast.ts` — mati (use-toast digantikan sonner sejak v5).
- `tailwind.config.ts` — TIDAK PERNAH dimuat: proyek memakai Tailwind v4 (@tailwindcss/postcss)
  yang membaca token dari `@theme inline` di `globals.css`; tanpa directive `@config`, file config
  v3 diabaikan. Semua token (--color-*, --radius) terverifikasi ada di globals.css.
- `examples/websocket/` — demo scaffold yang sudah rusak referensinya (import socket.io yang tak
  ada di root) dan dikecualikan dari eslint.
- `src/app/api/route.ts` — sisa scaffold "Hello, world!", tidak ada pemanggil.
- Artefak verifikasi: `tool-results/` (±14,5 MB screenshot), `upload/` (0,7 MB).

Untuk menambah kembali komponen shadcn: `bunx shadcn@latest add <nama>` (components.json utuh).

## 3. Perbaikan kode

- `next.config.ts`: `poweredByHeader: false` + `compiler.removeConsole` (prod membuang
  console.log; error/warn dipertahankan) — bundle produksi lebih ramping, header fingerprint hilang.
- `src/app/api/scrape/route.ts`: path `down.json` hardcoded `/home/z/my-project/...` →
  `path.join(process.cwd(), ...)` (pola yang sama dengan `readScraperStatus()` di trend-engine).
  Rapuh jika path deploy berubah; kini portabel.
- `.gitignore`: + `session.json` (cookie login — SEBELUMNYA TIDAK di-ignore, risiko keamanan),
  `status.json`, `discovery.json`, `down.json`, `.supervisor.lock`, `__pycache__/`, `*.pyc`,
  `db/*.db-shm`, `db/*.db-wal` (sidecar transien SQLite), `tool-results/`, `upload/`,
  `public/*.zip` (artefak build), `*.tar`.
  Catatan: file yang sudah ter-commit tidak otomatis keluar dari index — jalankan
  `git rm --cached <file>` di platform bila ingin benar-benar keluar dari repo.

## 4. Audit yang TIDAK dieksekusi (butuh runtime/platform)

- `config.py` bot & `mini-services/trend-realtime-service/index.ts` masih memakai default path
  absolut `/home/z/my-project/...`. Benar di platform; bila suatu hari dijalankan di luar sandbox,
  ganti ke path relatif terhadap lokasi file (mis. `os.path.normpath(os.path.join(SERVICE_DIR, "..", "..", "db", "custom.db"))`)
  atau set env `SCRAPER_DB_PATH`. Tidak diubah karena bot adalah sistem produksi yang tidak bisa
  diuji dari mesin ini.
- API/DB sudah dalam kondisi teroptimasi dari iterasi v4–v7 (index lengkap, TTL cache meta 15s,
  raw SQL dedupe global, Cache-Control SWR di /api/videos, konsolidasi query) — tidak ada
  perubahan lagi yang layak tanpa pengukuran runtime.
- `public/trendpulse-source.zip` (35 MB) kini stale terhadap source baru — rebuild di platform
  bila fitur download dipakai.

## 5. Langkah setelah deploy ke platform

1. `bun install` (sinkron lockfile dengan package.json baru).
2. Restart dev server / container agar PrismaClient & config baru termuat.
3. Verifikasi cepat: halaman render, /api/meta 200, /api/videos 200, sync tombol jalan.
4. (Opsional) rebuild trendpulse-source.zip & `git rm --cached` artefak sesuai .gitignore baru.
